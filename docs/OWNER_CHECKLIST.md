# Что нужно сделать владельцу

Ключи и пароли не пересылайте в чатах и не кладите в репозиторий: их вписывают прямо на сервере
в файл `.env` (см. `docs/DEPLOY.md`).

## 1. Сразу — это дольше всего ждать

| # | Что сделать | Что передать разработчику |
|---|---|---|
| 1 | **Сервер (VPS) в России**: Selectel VDS 2-4-50 в Москве (2 ядра, 4 ГБ памяти, 50 ГБ), Ubuntu 24.04. Аккаунт — на ИП: договор, оплата и закрывающие документы на владельца. Данные покупателей по 152-ФЗ должны храниться в РФ | IP-адрес и доступ по SSH (ключ) |
| 2 | **Домен nsbtea.ru** — регистрировать на владельца (ИП): кто указан администратором, тот юридически и владеет доменом | Доступ к управлению DNS или готовность добавить две записи по инструкции |
| 3 | **Точка Банк**: интернет-эквайринг уже работает на витрине Точки — новый сайт принимает оплату через него же (карта и СБП на платёжной странице Точки). Спросить в чате поддержки Точки: (1) nsbtea.ru — новая торговая точка или смена адреса у текущей, и какой у неё `merchantId`; (2) подключены ли чеки (фискализация) для оплаты через API — если покупателям витрины приходят чеки, скорее всего да. В интернет-банке «Интеграции и API» выпустить ключ (JWT) с правами `MakeAcquiringOperation`, `ReadAcquiringData`, `ReadCustomerData`, `ManageWebhookData` | client_id, merchantId; JWT — вписать на сервере |
| 4 | **СДЭК**: договор интернет-магазина, в личном кабинете «Интеграция» → ключи API | client_id; секрет — вписать на сервере |
| 5 | **Бухгалтер**: система налогообложения и ставка НДС для чеков (сейчас — «УСН доходы, без НДС») | Ответ |
| 6 | **Telegram-бот**: создать в @BotFather | Имя бота; токен — вписать на сервере |

## 3. Наполнение — можно начинать сейчас

13. **Реквизиты ИП**: ФИО, ИНН, ОГРНИП, юридический адрес; телефон, Telegram, ВК, адрес самовывоза, часы работы.
14. **Документы**: оферта, политика обработки персональных данных, согласие на обработку — с реквизитами ИП.
    Обязательны для запуска: без них покупатель не сможет оформить заказ.
15. **Тексты**: о магазине и о себе, «Доставка и оплата», опт, выездные церемонии.
16. **Каждый чай**: фото (единый стиль, светлый фон), описание, характеристики, вкусовые ноты, параметры заваривания,
    цена, граммовки, остаток. Вносится в админке («Товары» → «Добавить товар», остаток — «Склад» → «Принять поставку»).
    Самая долгая часть — собирайте фото и тексты заранее.

## 4. Решить: где макет расходится с ТЗ

Всё — настройки в админке, можно поменять в любой момент. Сейчас стоит:

- **Чай недели**: скидка действует неделю, с четверга до следующего четверга (как в макете). Можно «только в четверг» (как в ТЗ).
- **Курьер по Владимиру**: бесплатно (ТЗ). В макете — 300 ₽, бесплатно от 3 000 ₽.
- **Округление цены**: до рубля (ТЗ). В макете — до 10 ₽.
- **Оплата при получении**: выключена. Для чеков при оплате на месте нужна касса — уточнить у бухгалтера.

## 5. Проверить на тестовом сервере (с телефона)

- [ ] Войти в админку, привязать Telegram в «Мой профиль» (вход станет с кодом из бота).
- [ ] Пройти чек-лист запуска на главном экране админки.
- [ ] Завести 2–3 настоящих товара с фото, принять поставку.
- [ ] Купить на сайте с телефона: выбрать граммовку, оформить, оплатить (тестовая оплата).
- [ ] Получить уведомление в Telegram, провести заказ: собрать → передать → выполнен; проверить начисление баллов.
- [ ] Запланировать четверг, создать промокод, проверить цену на сайте.
- [ ] Пригласить сотрудника по ссылке, отозвать доступ.
- [ ] Перед запуском — один настоящий платёж и возврат (боевые ключи Точки).
