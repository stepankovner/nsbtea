# Журнал решений

Формат: дата — решение — причина. Новые записи — сверху.

- 2026-10-09 — На боевом сайте заказ принимается только при опубликованных оферте, политике и согласии (на тестовом — всегда). — SPEC 4.2: согласия «со ссылками на документы»; при начальном наполнении документы не опубликованы, и ссылки вели бы на «не найдено».
- 2026-10-09 — Ручное начисление и списание баллов — только владелец. — SPEC 7.1 («владелец может») и 10.9 (у сотрудника нет финансов).
- 2026-10-09 — Акции и промокоды из архива возвращаются выключенными. — Включение скидки должно быть осознанным действием.
- 2026-10-09 — Календарь четвергов показывает отдельно идущий чай недели прошлого четверга (режим «неделя», пт–ср). — Иначе с пятницы по среду владелец не видит действующую акцию.
- 2026-10-09 — `clear-test-data` — очистка пробных заказов, покупателей, баллов и писем перед запуском; только при `ENVIRONMENT=staging`, с подтверждением; остатки возвращаются строкой журнала на товар. — Каталог наполняется на тестовом сервере и переезжает вместе с базой.
- 2026-10-09 — Админка, товары: у опубликованных и скрытых товаров — сохранение кнопкой, у черновиков — автосохранение; черновик создаётся на шаге 1 (там же название — из него строится адрес). — Автосохранение опубликованного товара отправляло бы на сайт недописанную цену или текст.
- 2026-10-09 — Админка, товары: фото обрезаются до квадрата и уменьшаются до 2000 px в браузере, WebP делает сервер; предпросмотр собран в админке из витринных компонентов (в API нет режима предпросмотра). — Меньше трафика с телефона; покупатель видит то же, что в предпросмотре.
- 2026-10-09 — Админка: в выпадающих списках — системный `<select>`. — На телефоне открывается привычное системное меню.
- 2026-10-09 — Склад: поставка и инвентаризация — три шага (что → сколько → проверка «было → станет»), списание — два шага и подтверждение; после проведения — вкладка «История». Причина в инвентаризации и комментарий к списанию необязательны (как на сервере). — Главный сценарий с телефона должен быть коротким и проверяемым.
- 2026-10-09 — Акции и промокоды: окончание «23:59» или пустое время — до конца дня включительно (на сервер уходит полночь следующего дня по Москве). — Владелец мыслит днями, а не минутами.
- 2026-10-09 — Сотрудники: срок доступа — до конца выбранного дня по Москве, по умолчанию 30 дней; галочки уведомлений сохраняются сразу; кнопка «Сохранить» в настройках не выключается. — Денежное поле применяет значение при уходе из поля — на телефоне первое нажатие иначе терялось бы.

- 2026-10-08 — Проверка настроек (`python -m app.cli check-config`) запускается в Docker Compose перед миграциями; без ключей боевого режима API и воркер не стартуют. — Иначе uvicorn с несколькими процессами бесконечно перезапускает упавшие процессы, и сайт «висит» без понятной причины.
- 2026-10-08 — Отдельный шаг `media-init` выставляет владельца тома картинок; файлы резервных копий создаются с правами 600. — Общий том мог создаться пустым с владельцем root, и загрузка фото падала; в копии БД — персональные данные.
- 2026-10-08 — `infra/smoke-test.sh` — проверка после каждого запуска/обновления (сервисы, API и БД, сайт, robots, запись и раздача картинок, воркер, резервная копия). — Ловит ошибки окружения, которые не видны юнит-тестам (так найдены две ошибки выше).
- 2026-10-08 — `robots.txt` и адрес сайта читаются при запросе, а не при сборке. — Один Docker-образ для тестового (закрыт от поисковиков) и боевого сервера.
- 2026-10-07 — Sentry подключён в backend и воркере (`send_default_pii=False` — без персональных данных); во фронтенде пока нет. — Ошибки сервера важнее; `@sentry/nextjs` — тяжёлая зависимость, добавим после запуска при необходимости.
- 2026-10-07 — Админка: shadcn/ui (Radix) с отдельной нейтральной темой `.admin`, TanStack Query для данных, TipTap 3 для визуального редактора, dnd-kit для порядка фото и блоков, react-easy-crop для обрезки фото до квадрата, cmdk для поиска. — Доступные компоненты с крупными областями нажатия; без этих библиотек заметно сложнее сделать удобную работу с телефона.
- 2026-10-07 — Типы API во фронтенде генерируются из OpenAPI (`openapi-typescript` + `openapi-fetch`); CI проверяет, что они совпадают с backend. — Правило CLAUDE.md: типы не дублируются руками.
- 2026-10-07 — Дизайн витрины — по `docs/design/references/handoff` (финальный макет); шаг «два варианта дизайна» не нужен. — Макет уже согласован.
- 2026-10-06 — Без ключа Яндекс Карт выбор ПВЗ СДЭК работает списком (поиск города → пункты выдачи); с ключом — карта виджета СДЭК v4. — Виджет СДЭК без ключа карт не работает, а оформление заказа не должно зависеть от стороннего ключа.
- 2026-10-06 — Корневой сертификат Минцифры включён в образ backend. — API Точки использует сертификаты российского УЦ.
- 2026-10-06 — Уведомления и письма отправляются через outbox (запись в той же транзакции, доставка воркером с повторами). — Сбой Telegram или почты не ломает оплату и смену статусов, ничего не теряется.
- 2026-10-06 — Акции и чай недели действуют «динамически»: цена считается на момент запроса по расписанию, без фоновой задачи включения/выключения. — Нет риска, что акция не включилась из-за остановленного воркера.
- 2026-10-06 — Чай недели: по умолчанию скидка действует неделю — с четверга до следующего четверга (как в макете); в настройках можно выбрать «только в четверг» (как в ТЗ). — Расхождение макета и ТЗ; решает владелец.
- 2026-10-06 — Курьер по Владимиру по умолчанию бесплатный (ТЗ); стоимость и порог бесплатной доставки — настройки. В макете — 300 ₽, бесплатно от 3 000 ₽. — Расхождение макета и ТЗ; решает владелец.
- 2026-10-06 — Цена строки округляется до целого рубля half-up (ТЗ), а не до 10 ₽, как в примерах макета. — Жёсткое правило ТЗ.
- 2026-10-06 — Оплата при получении (самовывоз) выключена по умолчанию. — Чек 54-ФЗ при оплате на месте требует кассы; включать после консультации с бухгалтером.
- 2026-10-06 — Частичный возврат не меняет статус заказа, сумма возвратов хранится в заказе; полный возврат — статус «Возврат». — Частичный возврат (например, один чай закончился) — обычная операция, заказ продолжает жить.
- 2026-10-06 — Один столбец остатка у товара (граммы для чая, штуки для штучных) + журнал движений. — Проще и надёжнее двух столбцов; тип товара определяет единицу.
- 2026-10-06 — SQLAlchemy `eager_defaults` для всех моделей. — В асинхронном режиме значения по умолчанию из БД нельзя «догрузить» лениво.

- 2026-10-06 — Оплата через API интернет-эквайринга Точки (платёжные ссылки с фискализацией). — ИП уже обслуживается в Точке и принимает оплату через её эквайринг; чеки 54-ФЗ формируют партнёры Точки, отдельная касса не нужна.
- 2026-10-06 — Чай учитывается в граммах, цена задаётся за грамм; наборы — штучный товар со своим остатком. — Позволяет продавать любые граммовки и блин целиком из одного остатка; наборы собираются заранее.
- 2026-10-06 — Списание остатка при создании заказа + автоотмена через 30 минут без оплаты. — Не даёт продать больше, чем есть, при одновременных заказах.
- 2026-10-06 — Баллы: 5% начисления, до 50% оплаты, начисление при статусе «Выполнен». — Решение заказчика; начисление после выполнения защищает от злоупотреблений отменами.
- 2026-10-06 — Вход покупателей без паролей (код на email, Telegram). — Меньше трения при оформлении; аудитория магазина в Telegram.
- 2026-10-06 — Уведомления владельцу только в Telegram. — Решение заказчика.
- 2026-10-06 — Своя админка вместо готового движка. — Нужна полноценная работа с телефона и простота для непрограммиста; готовые админки этого не дают.
