# Интернет-эквайринг Точки: требования и подключение

Заявку подаём, когда сайт открыт на https://nsbtea.ru с настоящим каталогом, реквизитами и документами:
банк проверяет живой сайт. До одобрения сайт работает с `TOCHKA_MODE=off` — покупатель видит
«онлайн-оплата подключается», заказ можно оформить в Telegram (или оплатить при получении, если включено).

Сверено с сайтом и документацией Точки 15.10.2026, источники — в конце.

## 1. Требования Точки к сайту и где они выполнены

| Требование банка | Где на сайте | Что сделать владельцу |
|---|---|---|
| Реквизиты: название ИП, ИНН, ОГРНИП (и адрес) | Подвал каждой страницы; «Контакты» → блок «Реквизиты» | Заполнить: админка → «Настройки» → «Магазин, реквизиты и контакты» → «Реквизиты ИП» |
| Товары: цена в рублях, описание, характеристики | Карточка товара: цена, описание, характеристики, условия хранения, срок годности | Внести все товары с фото и описанием; демо-товары — в архив |
| Условия оплаты: способы, сроки, порядок | «Доставка и оплата»: текст + блок «Оплата» из настроек; оформление заказа | Проверить текст страницы |
| Условия доставки: способы, стоимость, города | «Доставка и оплата»: блок «Способы доставки» из настроек | Цены курьера и адрес самовывоза: «Настройки» → «Доставка» |
| Условия возврата: причины, сроки, порядок | «Обмен и возврат» (черновик по ст. 26.1 ЗоЗПП); условия возврата есть и в упаковочном листе | Проверить с юристом, опубликовать |
| Политика конфиденциальности и согласие на обработку ПД | `/legal/privacy`, `/legal/consent`; при оформлении — отдельная галочка согласия со ссылкой на него | Тексты с реквизитами ИП, опубликовать |
| Публичная оферта | `/legal/offer`; галочка при оформлении | Текст, опубликовать |
| HTTPS с автоматическим редиректом | Caddy сам выпускает сертификат и переводит http → https; проверяет `infra/smoke-test.sh` | — |
| Какие карты принимаем (статья Точки о подготовке сайта) | Подвал, «Доставка и оплата», оформление: МИР, Visa, Mastercard российских банков и СБП | — |
| Русский язык | Весь сайт | — |
| Нет запрещённых товаров (рецептурные лекарства, табак, алкоголь) | Чай и посуда | — |

Без опубликованных оферты, политики и согласия боевой сайт не принимает заказы (SPEC 4.2).
Ход подготовки виден в админке: главный экран → «Подготовка к запуску».

## 2. Перед заявкой

- [ ] Сайт открыт на https://nsbtea.ru: `ENVIRONMENT=production`, `TOCHKA_MODE=off` (см. `docs/DEPLOY.md`).
- [ ] Чек-лист «Подготовка к запуску» в админке выполнен, кроме «Подключите онлайн-оплату».
- [ ] Каталог настоящий: у каждого товара фото, описание, цена; демо-товаров нет.
- [ ] Опубликованы оферта, политика, согласие, «Доставка и оплата», «Обмен и возврат», «Контакты».
- [ ] Бухгалтер подтвердил систему налогообложения и ставку НДС → «Настройки» → «Оплата и чеки».

## 3. Заявка

1. Веб-версия интернет-банка Точки → «Сервисы» → «Интернет-эквайринг» → заявка. Подаёт человек
   с правом подписи (владелец ИП). Точка рассматривает заявку около 10 минут и пишет в чат банка,
   подключение — обычно до 2 рабочих дней.
2. Сайт — `https://nsbtea.ru`. У ИП уже есть торговая точка витрины Точки: для сайта будет вторая
   (или банк сменит адрес у текущей) — уточнить в чате. Сайт работает с любым вариантом.
3. **Чеки по 54-ФЗ выбрать в заявке** — без них сайт оплату не создаст (оплата идёт сразу с чеком):

   | Вариант | Стоимость | Когда выгоднее |
   |---|---|---|
   | Сервис «Чеки» | 1% с оплаты, не меньше 5 ₽, без кассы | Оборот до ~150 000 ₽ в месяц |
   | Облачная касса (Точки или DigitalKassa) | от 1 500 ₽ в месяц | Оборот больше ~150 000 ₽ в месяц |

   Граница: 1% от 150 000 ₽ = 1 500 ₽. Вариант можно сменить позже.
4. Способы оплаты: карта и СБП. T-Pay и «Долями» — по желанию, комиссия выше.

Комиссия (тарифы Точки на 15.10.2026): карта — 2,8–3,2% в зависимости от оборота, СБП — 0,4–0,7%.
Деньги по карте приходят на следующий день, по СБП — сразу.

## 4. После одобрения

1. Интернет-банк → «Интеграции и API» → выпустить JWT-ключ с правами `MakeAcquiringOperation`,
   `ReadAcquiringData`, `ReadCustomerData`, `ManageWebhookData`; рядом — `client_id`.
   Ключ не пересылать: вписать на сервере в `.env` (`TOCHKA_JWT`, `TOCHKA_CLIENT_ID`).
2. На сервере: `docker compose --env-file ../.env exec api python -m app.cli tochka-info` — покажет код клиента,
   торговые точки, подключены ли чеки и способы оплаты и что вписать в `.env`
   (`TOCHKA_CUSTOMER_CODE`, `TOCHKA_MERCHANT_ID`, `TOCHKA_PAYMENT_MODES`). Пока есть «Нужно исправить» — дальше не идём.
3. `TOCHKA_MODE=production` → `docker compose --env-file ../.env up -d` →
   `exec api python -m app.cli register-tochka-webhook` (Точка проверит адрес тестовым запросом).
4. Проверка (Точка советует платёж на 1 ₽; у нас минимальная сумма — цена самого дешёвого товара):
   - [ ] Купить на сайте картой и через СБП → заказ «Оплачен», уведомление в Telegram, чек на почту.
   - [ ] Вернуть оплату из админки → деньги вернулись, пришёл чек возврата.
5. Витрину Точки оставить на 1–2 месяца с пометкой «Мы переехали на nsbtea.ru» (ROADMAP).

## 5. Открытые вопросы

- Формирует ли сервис «Чеки» чек возврата при возврате через API — проверить на шаге 4.4.
- Возврат продуктов питания надлежащего качества при дистанционной продаже — текст «Обмен и возврат» проверить с юристом.
- Нужен ли магазину аттестованный по 152-ФЗ сервер (Selectel VDS в этот сегмент не входит) — вопрос юристу.
