# Handoff: НСБ Чай — интернет-магазин китайского чая (Владимир)

## Overview
Сайт интернет-магазина китайского чая «НСБ Чай» (основатель — Никита Сергеевич Булич, НСБ — его инициалы). Продажа чая на развес с доставкой по Владимиру и России, «Чай недели» со скидкой 20%, запись на чайные церемонии и сплавы на сапах, заявка на выездную церемонию, оптовые заказы.

## About the Design Files
Файлы в этой папке — **дизайн-референсы, сделанные в HTML**: прототипы, показывающие внешний вид и поведение. Это не production-код. Задача — **воссоздать дизайн в целевом стеке** (если стека нет — выбрать подходящий, например Next.js + TypeScript + CSS Modules/Tailwind, с реальной корзиной и бэкендом заказов).

Открыть прототип: `site.dc.html` в браузере (рядом должны лежать `support.js`, `NsbLogo.dc.html`, `TeaCard.dc.html`, `image-slot.js`). Шаблон — между `<x-dc>` и `</x-dc>`, логика и данные — в `<script data-dc-script>` (класс `Component`, метод `renderVals()`).

## Fidelity
**High-fidelity.** Цвета, типографика, отступы и взаимодействия финальные. Тексты, сорта, цены, даты мероприятий — примеры; заменить реальными данными из CMS/админки. Плейсхолдеры `[адрес]`, `[телефон]` — заполнить.

## Карточка товара в каталоге (TeaCard)
Плитка 4:5 в цвете вида чая. Режим «С фото»: левые 70% — фото сухого листа (cover), правые 30% — цветная полоса с иероглифами (Noto Serif SC, `clamp(26px,2.4vw,34px)`, вертикально) и номером. Режим «Только иероглиф»: вся плитка цветная, иероглифы справа сверху, пиньинь слева сверху. Бейдж скидки — pill `#8E3236` в левом нижнем углу. Под плиткой: название (Prata 22), мета (тип · регион · год, mono 11 uppercase), линия, цена (красная со скидкой + зачёркнутая), кнопка-pill «В корзину».

## Interactions & Behavior
- **Чай недели**: каждый четверг владелец выбирает три чая; скидка 20% действует до следующего четверга. Дату «до …» считать как ближайший следующий четверг. В админке нужна настройка: список из 3 SKU + дата начала недели. Скидка применяется везде: плитки, страница товара, корзина.
- Цена за вес: `round(price50 * w / 50 * (скидка ? 0.8 : 1) / 10) * 10`.
- «В корзину» на плитке добавляет 50 г и показывает тост внизу слева (2.6 с) со ссылкой в корзину.
- Навигация к «Чай недели», «Оптовые заказы», «О магазине» — плавный скролл на главной с учётом sticky-шапки (~70px).
- Валидация: телефон ≥ 10 цифр; имя обязательно; адрес обязателен для курьера/СДЭК; для записи на событие — имя и телефон; гостей не больше оставшихся мест.
- Hover: тёмные кнопки → `#8E3236`; outline-кнопки → заливка `#1D231B`; ссылки-заголовки → `#8E3236`; строки и плитки — лёгкое изменение прозрачности.
- Адаптив: всё на flex-wrap / grid auto-fit; без фиксированных ширин.
